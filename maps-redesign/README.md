# 地图重设计数据（source of truth）

本次改动按《王国保卫战》的三条设计语言重画了三张战役地图：
**多发卡折返**（制造并行路段供交叉覆盖）、**汇流绞索点**、**高地塔位换射程**。

## 文件说明

| 文件 | 说明 |
|---|---|
| `new_maps.json` | 三张地图的完整几何：`pads`（含 `height` 高地加成）、`route`（主推进路线）、`branch`（第 5 波后开放的分路）、`ore`（4 个精矿点） |
| `plan_01.svg` | 断崖前哨 / frontier 方案图 |
| `plan_02.svg` | 鹰脊高原 / highlands 方案图 |
| `plan_03.svg` | 熔火要塞 / volcano 方案图 |

## ⚠️ 重要：不要丢这份数据

本仓库目前**只提交构建产物**（`_next/static/chunks/page-D_63204g.js`），没有源码。
这次的重设计是直接打进构建产物里的，因此：

- **下次 `npm run build` 会把这套地图覆盖回旧数据**；
- 重新打包前，请把 `new_maps.json` 里的三组值回填到源码中的地图表（变量 `tu`）、
  分路表（`uu`）与精矿点表（`su`）；
- 坐标系完全一致：地图坐标，`K=1.75` 缩放到世界坐标，入口固定 `x=-35`，终点 `x=980`。

| 检查项 | 阈值 | 结果 |
|---|---|---|
| 阵地数量 | ≤ 14（工具限制 0..13） | 13 / 13 / 12 ✓ |
| 阵地到路面中心线距离 | ≥ 45 | 50 / 45 / 45 ✓ |
| 阵地最小间距 | ≥ 94 | 94 / 120 / 94 ✓ |
| 每个阵地覆盖路段数 | ≥ 1 | 最少 2 / 2 / 3 ✓ |
| 两条路线终点一致 | 必须相同 | ✓ |
| 精矿点数量 | 恰好 4 | ✓ |
